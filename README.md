# OvaNet AI

AI-assisted PCOS risk assessment from ovarian ultrasound — decision-support research prototype.

**This tool does not diagnose and is not a validated medical device.**

## Status
Day 1 of a 10-day hackathon build. See `docs/status/` for progress and `docs/CONTRACTS.md` for module interfaces.

## Setup
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
pytest
```
